# Betsu-RPG
Projeto desenvolvido em Python para auxiliar na administração e organização do RPG Betsu, automatizando diversas mecânicas importantes da mesa, como cálculos de atributos, progressão de status, gerenciamento de recursos e geração procedural de criaturas.

O sistema foi estruturado para tornar as sessões mais rápidas e imersivas, reduzindo a necessidade de cálculos manuais durante o jogo.
Dentre as automatizações estão:
## Sistema de Spawn
Baseados em probabilidade, raridade, região e horário, permitindo que diferentes criaturas apareçam de forma dinâmica e contextual dentro do universo do RPG.
Toda a lógica foi organizada de forma escalável, facilitando a expansão futura do sistema com novos monstros, regiões, mecânicas e regras.
## Sistema de Atributos
Cálculos automáticos para atributos dos personagens, incluindo vida, mana, stamina, resistências físicas e mágicas, movimentação, alcance e progressão por nível.
